# Nyvangsskolen 1999

Gå en tur gennem Nyvangsskolen på Rindsvej i Randers, som den stod i efteråret 1999, og møblér den selv. Skolen blev taget i brug i 1952 og revet ned i 2016.

**https://nyvang.gitato.net/**

Siden er én HTML-fil, der bygger skolen i browseren. Den er lavet til Chrome eller Edge på en computer med mus og tastatur; på en telefon kan man gå rundt, men ikke møblere ordentligt.

## Hvad der ligger her

| Fil | Hvad |
|---|---|
| `index.html` | Hele simulationen: model, motor og three.js i én fil. |
| `assets/audio/` | Fodtrinslyde. |
| `404.html`, `robots.txt`, `del.jpg`, `CNAME`, `.nojekyll` | Det, GitHub Pages og delte links skal bruge. |
| `CREDITS.md`, `THIRD-PARTY-NOTICES.md`, `LICENSES/` | Kreditering og licenser. |

Filerne er skrevet af en generator ud fra en geometrisk model af skolen og bliver overskrevet, hver gang siden bygges. Ret derfor ikke i dem her.

## Kilder og kreditering

- Bygningen er rekonstrueret efter hovedprojektet fra 1950 og byggesagerne 1952-1998 i Randers Kommunes byggesagsarkiv. Ingen tegninger og ingen fotos er med her.
- Mål og rumdeling følger tegningerne. Farver, gulve og inventar er skøn.
- Fodtrinslyde: Kenney, CC0 1.0 (https://kenney.nl/assets/impact-sounds). Se `CREDITS.md`.
- 3D-motor: three.js 0.165.0, MIT. Se `THIRD-PARTY-NOTICES.md`.

## Hjælp med at møblere

Husker du, hvordan der så ud? Sæt det ind med knappen Møbler, og tryk Indsend. Det, du har sat ind, flyttet eller fjernet, bliver sendt til den, der står for siden, og set igennem, før noget kommer med i skolens møblering.

## Dine data

Det, du møblerer, gemmes i din egen browser. Trykker du Indsend, sendes det, du har sat ind, flyttet eller fjernet, og det navn og den besked, du selv skriver (begge er valgfri). Det sendte kan blive en del af den offentlige model; navn og besked bliver ikke vist offentligt. Ellers henter siden kun sine egne filer, bruger ingen cookies og sender ikke noget om dig videre.
